# プライバシーポリシー

最終更新: 2026年10月5日

Streamers' Games（ストリーマーズゲームス、代表 TOKKY。以下「開発者」）は、ゲーム「GODWATCH DUNGEON」（以下「本ゲーム」）での情報の扱いを次のとおり定めます。

## 1. YouTube API サービスの利用
本ゲームの「配信モード」は YouTube API サービスを使います。配信モードを使う方は、[YouTube 利用規約](https://www.youtube.com/t/terms) に同意したものとみなします。Google による情報の扱いは [Google プライバシーポリシー](https://policies.google.com/privacy) をご覧ください。

配信モードは、ゲーム内の設定で「YouTube の規約に同意する」をオンにするまで YouTube に接続しません。

## 2. 本ゲームが読む情報
配信モードで接続している間だけ、利用者が指定したライブ配信について、YouTube から次の情報を読みます。

- ライブチャットのメッセージ（コメント）の件数と、メッセージの識別子
- Super Chat・Super Sticker の金額の区分と、送った方の表示名

Twitch を選んだ場合は、利用者が指定したチャンネルのチャットを、ログインせずに読みます（読むだけで、書き込みはしません）。

- チャットの発言の件数と、発言の識別子
- Bits（投げ銭）の量、サブスク・ギフトサブの有無と、その方の表示名

## 3. 情報の使い方
- Super Chat の金額の区分・Twitch の Bits の量・サブスク・ギフトサブに応じて、ゲーム内の出来事（神さまの演出）を起こします。送った方の表示名は、その出来事の表示に使います。
- コメントの件数は、ゲーム内の回復（観客神の声援）に使います。コメントの本文は使いません。

## 4. 保存と共有
- 上記 2 の情報は、ゲームを動かしている間だけ PC のメモリ上で使い、**保存しません**。ゲームを終えると消えます。
- 利用者が入力した YouTube Data API のキー、チャンネル、配信の URL は、利用者の PC の中の設定ファイルにだけ保存します。開発者や第三者へ送ることはありません。
- Steam 版では、セーブデータ（冒険の進み具合。個人を特定する情報は含みません）を Steam クラウドで同期し、実績を Steam に記録します。API キーなどの設定ファイルは同期しません。
- 本ゲームは、開発者のサーバーへ情報を送りません。広告や分析のための情報集め、Cookie の利用もしません。
- お問い合わせフォーム（Google フォーム）で送っていただいた内容とメールアドレスは、お問い合わせへの返信と不具合の調査にだけ使い、ほかの目的には使いません。
- 第三者へ情報を渡すことはありません（法令に基づく場合を除く）。

## 5. 情報の消し方
- ゲーム内の 設定 → 配信 で、API キー・チャンネル・URL を消せます。同意のチェックを外すと、配信モードは接続しなくなります。
- 設定ファイルは次の場所にあります。ゲームを削除したあと、このフォルダを消すとすべて消えます。
  `%USERPROFILE%\AppData\LocalLow\StreamersGames\GODWATCH DUNGEON\`
- API キーそのものは Google Cloud コンソールで削除・無効にできます。

# Privacy Policy

Last updated: October 5, 2026

Streamers' Games (run by TOKKY, "we") describes here how the game "GODWATCH DUNGEON" (the "Game") handles information.

## 1. Use of YouTube API Services
The Game's Stream Mode uses YouTube API Services. By using Stream Mode you agree to be bound by the [YouTube Terms of Service](https://www.youtube.com/t/terms). See the [Google Privacy Policy](http://www.google.com/policies/privacy) for how Google handles information.

Stream Mode does not connect to YouTube until you turn on "I agree to the YouTube Terms" in the in-game settings.

## 2. Information the Game reads
Only while Stream Mode is connected, the Game reads the following from YouTube for the live stream you specify:
- The number of live chat messages and their message IDs
- The amount tier of Super Chats and Super Stickers, and the sender's display name

If you choose Twitch, the Game reads the chat of the channel you specify without logging in (read-only; it never posts):
- The number of chat messages and their message IDs
- The amount of Bits, whether a sub or gift sub occurred, and the user's display name

## 3. How it is used
- The Super Chat amount tier, the amount of Twitch Bits, and subs/gift subs trigger in-game events (the gods' interventions). The sender's display name is shown with that event.
- The number of comments is used for an in-game heal (the gods' cheering). Comment text is not used.

## 4. Storage and sharing
- The information in section 2 is used only in memory while the Game is running and is **never stored**. It is gone when you quit.
- Your YouTube Data API key, channel and stream URL are stored only in a settings file on your PC. They are never sent to us or to any third party.
- On Steam, your save data (adventure progress; no personally identifying information) is synced with Steam Cloud, and achievements are recorded on Steam. Settings files, including your API key, are not synced.
- The Game sends no information to our servers. It does no advertising or analytics tracking and uses no cookies.
- What you send through the contact form (Google Forms), including your email address, is used only to reply to you and to investigate bugs.
- We do not share information with third parties, except where required by law.

## 5. Deleting your information
- In Settings → Stream you can clear the API key, channel and URL. Turning off the consent toggle stops Stream Mode from connecting.
- The settings file is stored in `%USERPROFILE%\AppData\LocalLow\StreamersGames\GODWATCH DUNGEON\`. Deleting this folder removes everything.
- You can delete or disable the API key itself in the Google Cloud console.
